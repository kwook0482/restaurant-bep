# 우리 가게 손익분기점 계산기

## 파일 구성
- `index.html`: 입력 화면과 결과 화면
- `style.css`: 화면 디자인 및 모바일 대응
- `script.js`: 계산, 화면 전환, 그래프 갱신 및 조작 버튼

## 실행 방법
1. ZIP 파일을 압축 해제합니다.
2. 세 파일을 같은 폴더에 둡니다.
3. `index.html`을 더블 클릭하면 브라우저에서 열립니다.

인터넷 연결, 서버, 외부 라이브러리, 유료 API가 필요하지 않습니다.

## 현재 계산 방식
- 매달 나가는 돈 = 월세·관리비 + 직원 월급 + 공과금·기타 비용
- 예상 총비용 = 매달 나가는 돈 + 월 매출 × 매출 연동 비용 비율
- 예상 손익 = 월 매출 - 예상 총비용
- 손익분기점 매출 = 매달 나가는 돈 ÷ (1 - 매출 연동 비용 비율)

## 유의 사항
이 도구는 간이 추정용입니다. 세금, 대출이자, 감가상각, 사업주 인건비 등 입력하지 않은 비용이 있으면 실제 손익과 다를 수 있습니다. 2번 항목은 식재료비뿐 아니라 포장비·카드 수수료 등 매출에 따라 달라지는 비용을 가능한 한 합산한 비율로 입력하도록 안내합니다.

## 그래프 조작과 입력값 연동
결과 화면에서 고정비, 비용 비율, 예상 매출 조작 버튼을 누르면 입력값과 그래프가 함께 갱신됩니다. 입력 화면으로 돌아가면 변경된 값이 입력란에 표시됩니다. 새로고침 후 값 저장 기능은 첫 버전에서 제외했습니다.
